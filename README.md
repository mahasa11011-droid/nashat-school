# منصة النشاط المدرسي

موقع النشاط الطلابي لـ **مدرسة الموهوبين التقنية الثانوية بنات** — إدارة تعليم الرياض.

صفحة واحدة تعرض الإعلانات، الخطة الأسبوعية، المناسبات القادمة، صور الأنشطة، والحائط
الإلكتروني. تديره رائدة النشاط بعد تسجيل الدخول، ويتصفحه الجميع دون تسجيل.

**الموقع:** https://mahasa11011-droid.github.io/nashat-school/

---

## ⚠️ خطوة إلزامية بعد هذا التحديث

سُحبت كلمة المرور من داخل الصفحة، وصار الدخول عبر **Supabase Auth**. الموقع يعمل
للزوار كما هو، لكن **لن تتمكني من الدخول كرائدة نشاط حتى تُنجزي الخطوتين التاليتين**:

### ١. أنشئي حساب رائدة النشاط
Supabase Dashboard → **Authentication** → **Users** → **Add user** →
أدخلي بريدًا إلكترونيًا وكلمة مرور، وفعّلي *Auto Confirm User*.

هذا هو الحساب الذي ستستخدمينه في زر «دخول رائدة النشاط».

### ٢. طبّقي سياسات الصلاحيات
Supabase Dashboard → **SQL Editor** → **New query** → الصقي محتوى
[`schema.sql`](./schema.sql) كاملًا ثم **Run**.

بدون هذه الخطوة تبقى قاعدة البيانات مفتوحة للكتابة من أي شخص على الإنترنت.

### ٣. تأكّدي أن القفل يعمل
افتحي الموقع في نافذة تصفح خفي (بدون تسجيل دخول) وشغّلي هذا الأمر في الطرفية:

```bash
curl -s -X POST \
  'https://spefcltrdvkgzikrmayx.supabase.co/rest/v1/announcements' \
  -H 'apikey: <المفتاح العام>' \
  -H 'Content-Type: application/json' \
  -d '{"title":"اختبار","body":"احذفيني"}'
```

النتيجة المطلوبة:

```json
{"code":"42501","message":"new row violates row-level security policy"}
```

أي نتيجة أخرى تعني أن الجداول ما زالت مفتوحة — راجعي الخطوة ٢.

## البنية

```
index.html    الموقع كاملًا: HTML + CSS + JavaScript في ملف واحد
schema.sql    جداول قاعدة البيانات وسياسات الصلاحيات ومخزن الصور
```

لا يوجد أمر بناء ولا حزم npm. أي تعديل على `index.html` يُنشر تلقائيًا عبر
GitHub Pages عند الدفع إلى `main`.

## التقنيات

| الطبقة | الأداة |
|---|---|
| الواجهة | HTML و CSS مكتوبان يدويًا، خطا Cairo و Tajawal |
| البيانات | Supabase (PostgreSQL + Storage + Auth) |
| العميل | `@supabase/supabase-js@2.112.4` من esm.sh — **النسخة مثبّتة عمدًا** |
| الاستضافة | GitHub Pages من فرع `main` |

## قاعدة البيانات

| الجدول | المحتوى | من يكتب فيه |
|---|---|---|
| `announcements` | الإعلانات | رائدة النشاط |
| `weekly_plan` | الخطة الأسبوعية | رائدة النشاط |
| `events` | المناسبات العالمية | رائدة النشاط |
| `photos` | روابط صور الأنشطة | رائدة النشاط |
| `wall_posts` | رسائل الحائط | **الجميع** (الحذف لرائدة النشاط) |

مخزن الصور: `nashat-photos` — القراءة للجميع، والرفع لرائدة النشاط فقط.

## المفاتيح

`SUPABASE_URL` و `SUPABASE_KEY` في `index.html` مفتاحان **عامّان** (publishable)،
ووجودهما في الكود سليم ومقصود — فهما مصمَّمان للعمل داخل المتصفح. الحماية الحقيقية
هي سياسات RLS في `schema.sql`، لا إخفاء المفتاح.

⚠️ لا تضعي مفتاح `service_role` في هذا الملف إطلاقًا.

## التشغيل محليًا

```bash
python3 -m http.server 8000
# ثم افتحي http://localhost:8000
```

## مهام متكرّرة

**تغيير بيانات المدرسة** — قسم `<section id="school-info">` في `index.html`.

**بداية فصل دراسي جديد** — سجّلي الدخول، ثم احذفي أسابيع الفصل السابق من الخطة
وأضيفي الأسابيع الجديدة. الترتيب يتم حسب الفصل ثم رقم الأسبوع.

**حذف رسالة غير لائقة من الحائط** — سجّلي الدخول، ثم اضغطي زر × على البطاقة.

**تغيير كلمة المرور** — Supabase Dashboard → Authentication → Users → المستخدم →
Reset password. لا تُكتب كلمة المرور في الكود.
